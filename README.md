# Axis & Allies (2004) Modernization

Mod files, tools and an installer that make TimeGate's *Axis & Allies* (2004 RTS, v1.0.5.0, build 4129.7) run well on Windows 11 at 4K. No game files are included; you need your own copy.

Plan and full change log: [modernization plan doc](https://claude.ai/code/artifact/3d00b4da-e290-4bc4-a95a-6d7bdebf5dce)

## Install

```powershell
pwsh -ExecutionPolicy Bypass -File install.ps1 -GameDir "C:\path\to\Game Files"
```

Requires Python 3 on `PATH` and internet access (to download dgVoodoo2, DXVK, Liberation Sans and Real-ESRGAN from their official releases, and Pillow/numpy from PyPI). The UI art step needs a Vulkan GPU.

## Widescreen UI

The engine lays the UI out in a virtual `InterfacePositioningWidth` x `InterfacePositioningHeight` space (1024 x 768, in `AVars.tgi`) and scales each axis to the screen, so 16:9 stretched it. `tools/widescreen.py` (run by `install.ps1 -Aspect 16:9`) generates loose overrides from the installed game's data:

- `AVars.tgi`: `InterfacePositioningWidth = 768 * aspect` (1365.33 for 16:9), so the UI keeps its proportions.
- Main/Single Player/Multiplayer menu column moved to the right edge; 3D menu background stays full width.
- In-game HUD: control panel art cut into five slices per skin (default + 5 nations, 3 resolution variants), minimap left, command panel right edge, info panel centered with the nation emblem intact.
- Dialogs and in-game popups centered.
- Full-screen menu screens (options, staging, campaign, dynamic campaign chooser, debriefing, scoring, credits, lobby, loading) shown as a centered 4:3 box.
- Campaign world map: the bottom control panel is a centered 4:3 box (its art has no part that stretches cleanly), with the minimap, tooltips and dialogs following it; the politics list stays at the right edge.
- Anchored tooltips (`anchored_tooltip_x` is the tooltip's right edge in screen units) move with the panel they belong to, in-game and on the campaign map.

Generated files are listed in `data/widescreen-generated.txt` and removed on the next run; `install.ps1 -Aspect 4:3` restores the original layout. Pick 3840x2160 (or any 16:9 mode) in Options. dgVoodoo also adds the largest 4:3 mode (2880x2160 on 4K) if you prefer the original layout pillarboxed.

## High-resolution UI art

UI textures are referenced as `/UI/%s/...`; `AA.exe` fills `%s` with the screen width and falls back to the base art (made for 1024x768) when that folder is missing, so at 4K the game used to magnify the base art 2.8x with nearest filtering. The 800 and 1280 sets are the base art rescaled by width/1024, tiled borders included. `tools/upscale_ui.py` (run by `install.ps1 -UiArt 3840x2160`) builds a `3840` set the same way: base size x screenH/768 (2.8125), rounded up to powers of two (the engine stretches every texture to that on load anyway), from the 1280 art where it exists, through Real-ESRGAN `realesrgan-x4plus` (RGB and alpha separately) and Lanczos. Covers ~1,500 textures: menus, HUD, dialogs, campaign map UI, tech/property icons, and each nation skin's versions.

- Real-ESRGAN ncnn-vulkan (BSD-3) is downloaded once into `.cache/esrgan`; a venv with Pillow and numpy into `.cache/venv`; 4x results are cached in `.cache/upscale` by source hash, so re-runs take seconds. First run ~2.5 minutes on an RX 9070 XT.
- Loose files under `data/**/3840/` and `skins/<nation>/**/3840/`, listed in `data/upscale-generated.txt`; `install.ps1 -UiArt off` removes them.
- Icons and pictures the game loads by a fixed path are replaced in place at the same size factor (`--no-inplace` skips them): recruit, building, tech, property, ability and message-log icons, campaign briefing pictures, general portraits, nation emblems, campaign-map division icons and remaining UI pieces.
- PNGs are written with a single `IDAT` chunk: the game's loader reads only the first one (every shipped PNG has one), and multi-chunk files rendered as garbage.
- Kept at the shipped size (`FIXED_SIZE`): textures the game uses at their exact pixel size. Larger command-grid frames gave sheared white garbage over every button; larger minimap icons were drawn into the minimap pixel for pixel, big and white; unit banners and nation badges are combined into one image, likely the same way.

## Model and terrain textures

`tools/upscale_textures.py` (run by `install.ps1`, `-Textures off` removes it) upscales the DDS textures of units, buildings, doodads, terrain, roads, effects and the campaign world map. Colour goes through Real-ESRGAN with texture-trained models: **UltraMix Balanced** for terrain and roads, **UltraSharp** for everything else (compared against realesrgan-x4plus, Remacri, NMKD Siax and Nomos8kSC on grass, rock, sand, a building, a tank and the world map: x4plus smooths grain flat, Remacri adds a crosshatch lattice, Siax checker noise, Nomos stays soft). Both models are from Upscayl v2.15.0 in ncnn format and are CC BY-NC-SA 4.0, so non-commercial use only. Alpha does not go through the model, because most of these textures use it as a binary team-colour or cut-out mask or a soft ground blend: it is Lanczos-resized and binary masks are re-thresholded. Each texture is re-encoded by DirectXTex `texconv` (MIT, downloaded once into `.cache`) to its original format (DXT1/DXT3/DXT5) with a full mipmap chain and a DX9 header, and written as a loose override at the same path.

| Art | Factor | Cap |
| --- | --- | --- |
| Units, buildings, campaign world map, doodads, shared models, roads, bridges, flares, special ops | 4x | 1024 px (world map 2048) |
| Terrain ground tiles (409 TGA) and water frames, upscaled as a 3x3 wrap so they still tile | 4x | 512 px |
| Effects, trailers, generals, cutscene | 2x | 512-2048 px |

4x is the model's native factor; more (8x, 16x) would only re-enlarge its output or be shrunk away again by mipmapping at 4K, and would multiply memory use in a 32-bit process with a 2 GB texture budget. Buildings get 4x because zoomed in they are ~1000 px wide on a 4K screen. Factors are in `GROUPS` at the top of the script. The ground is TGA, not DDS (the terrain DDS files are only water animation frames); those tiles are written back as 32-bit TGA, and because Real-ESRGAN smooths fine grain such as grass and sand flat, the high frequencies of a plain Lanczos upscale are blended back in proportion to the detail lost (rock and cracks, which the model sharpens, are left alone). The engine blends terrain on the GPU into the terrain texture pool, so bigger tiles are safe. Listed in `data/textures-generated.txt`.

The mouse cursor frames (32x32) are upscaled by screen height / 1080 (2x at 2160) with their `hotspot_offset` scaled to match (`data/Cursors/`), by `upscale_ui.py --cursor-scale`.

## ReShade (optional, installed separately)

ReShade 6.8 (32-bit) works on top of dgVoodoo: in its installer pick **Direct3D 10/11/12** (it becomes `dxgi.dll`; choosing Direct3D 9 would overwrite dgVoodoo's `D3D9.dll`). Working settings are kept in `reshade/` (copy both files next to `AA.exe` while the game is closed; ReShade saves over them on exit):

- Depth (Add-ons > Generic Depth): the 3840x2160 D24S8 buffer with "Copy depth buffer before clear operations" on (`[DEPTH] DepthCopyBeforeClears=1`); without it ReShade only sees the HUD's depth.
- `RESHADE_DEPTH_LINEARIZATION_FAR_PLANE=50` (default 1000 renders the whole RTS scene as near-black depth).
- Packages: Standard effects, SweetFX, qUINT, iMMERSE. Effect order: UIMask_Top, iMMERSE MXAO (High, radius 2.0, amount 0.9, fade 1.0; the default fade 0.25 hides it at RTS camera height), Lightroom (contrast +0.12, vibrance +0.20, saturation +0.05), iMMERSE Sharpen 0.5, iMMERSE SMAA (forced MSAA in dgVoodoo draws seams on the terrain), UIMask_Bottom.
- HUD mask: `tools/reshade_uimask.py <game dir> "<game dir>/reshade-shaders/Textures/UIMask.png"` builds it from the real control-panel art of all nation skins placed by the widescreen layout, plus the top-left bars; white = HUD, which UIMask restores so grading and sharpening only touch the 3D scene. Popup dialogs are not masked.

## Layout

- `mod/` — files copied into the game folder as-is. Loose files under `data/` override the same paths inside `Data.rwd`.
- `tools/` — `rwd.ps1` (list/extract `.rwd` archives), `laa.py`, `ttfinfo.py`, `tga2png.py`, `capture_menu.ps1` (launch + screenshot main menu), `peinfo.ps1`, `aa_re.py` (strings/constants/xrefs/disassembly, needs capstone), `memscan.py` (read-only memory scan of a running AA.exe, incl. `ves` to list top-level UI elements), `rwd.py` (Python archive reader), `fonts.py` (font overrides), `exe_patch.py` (checked, reversible AA.exe byte patches), `widescreen.py` (widescreen UI generator), `upscale_ui.py` (high-resolution UI art set, icons, cursor), `upscale_textures.py` (model and terrain textures), `graphics.py` (rendering settings), `ui_layout.py` (index UI layout entries / match them to runtime elements).

## Engine notes

- 32-bit, Direct3D 9 via Gamebryo; settings in `UVars.tgi` / `AVars.tgi`; user settings saved to `Documents/A&A/data/User/UVars.tgi`.
- `.rwd` = TGCK archive, uncompressed; directory at the end, entry offsets relative to the Files section (byte 30).
- Fonts: size = `size * screenH / InterfacePositioningHeight`, created with GDI+ in points, so at 150% Windows scaling (144 DPI) glyphs came out 1.5x larger than the cells sized for them. `exe_patch.py` switches to pixels and `fonts.py` scales sizes by 4/3 (= points at 96 DPI).
